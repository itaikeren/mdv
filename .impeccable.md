# Impeccable Design Context

## Design Context

### Users
Developers (and their AI agents) who write, preview, publish, and share markdown.
Human visitors evaluate the product signed-out at `/`; agents use the MCP endpoint.
Context of use: a developer's desk, usually with a dark editor/terminal nearby.

### Brand Personality
Engineered, precise, quietly confident. A modern developer tool that takes craft
seriously — fast, unflashy, and clearly built by people who live in editors.
Three words: **precise, contemporary, terminal-native.**

### Aesthetic Direction
**Modern dev workstation.** Contemporary product polish in the spirit of Vercel,
Linear, and Railway — but with genuine terminal DNA, not skeuomorphic terminal
cosplay. A deliberate step up from the earlier GitHub-terminal look.

Typography (the core move — no longer mono-everywhere, but mono-forward):
- **Geist Mono** — the default voice: all UI, chrome, labels, buttons, metadata,
  code, and the editor textarea. Mono carries the dev character.
- **Geist Sans** — reserved for the long-form reading surface (rendered markdown
  in the preview / share / public views), opted into via `.prose` / `.font-sans`.
- **Pixelify Sans** — the lowercase `mdv` brand wordmark and the odd tiny accent.
  Used sparingly.

Everything keys off the `--term-*` tokens (retuned in OKLCH), so both themes update
in lockstep:
- Dark-first (dev context); light fully supported. Clerk UIs follow the theme via
  `@clerk/themes` (dark baseTheme in dark mode) wired through a `ClerkWithTheme`
  wrapper in `main.tsx`.
- Refined near-black neutrals faintly tinted toward the signature green hue.
- One accent — the terminal green — used sparingly (~10% weight): prompts, links,
  active state, focus. Primary buttons are high-contrast near-white on dark.
- **Boxy** by design: buttons, controls, and panels stay sharp (terminal). Only
  selection/hover highlights (sidebar rows, active toggle segment, small chips)
  get a hair of rounding via `--radius-sm`. Tuned in one place: the `--radius-*`
  tokens (`--radius-sm: 4px`, `--radius: 0`, `--radius-lg: 0`).
- The rendered-markdown reading column is capped (~70ch) and centered inside its
  full-width box, like the typography plugin default.

Anti-references: old-GitHub chrome; walls of undifferentiated mono; generic SaaS
gradients, glassmorphism, gradient text, identical icon-card grids.

### Design Principles
1. **Mono is the voice, sans is for reading.** Geist Mono carries UI/chrome; Geist
   Sans is scoped to long-form rendered markdown.
2. **One accent, one token system.** Green is rare and meaningful; every surface
   flows from the `--term-*` OKLCH tokens so themes stay coherent.
3. **Boxy, not rounded.** Sharp terminal corners; rounding only on hover/selection.
4. **The document is the product.** The rendered-markdown reading experience gets
   first-class typography and a comfortable measure.
5. **Fast is a feature.** Self-hosted variable fonts, inline SVG, CSS-only motion,
   no unnecessary runtime deps.
